# Emulator feature checklist

Core features needed for a usable emulator frontend:

- [ ] Display video output with configurable screen layout, size, and fullscreen mode.
- [ ] Play audio output with configurable device and volume.
- [ ] Support controls from a gamepad and keyboard, with configurable bindings.
- [ ] Support touch input for the lower screen.
- [ ] Support microphone input when a host microphone is available.
- [ ] Provide an in-game overlay for configuration and savestate save/load.
- [ ] Don't turn off the screen during inactivity.
- [ ] Save a savestate automatically when the emulator exits; report save failures.
- [ ] Update Real Time Clock on resume.
- [ ] Retroachievement softcore support.
