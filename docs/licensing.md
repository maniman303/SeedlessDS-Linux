# Licensing and redistribution

The installed runner includes the SeedlessDS-Core license and notices for Lua, the LZMA SDK, zlib, libarchive and unarr under `share/licenses/`. The generated runtime inventory under `share/seedlessds/` identifies the core revision and statically embedded application libraries.

Redistributors must preserve the installed notices and follow each upstream project's license terms. Source for SeedlessDS-Core and dependency inputs is identified by the pinned revisions and URLs/checksums in this repository; provide corresponding source and local integration patches when distributing binaries where the applicable license requires it. This project does not package ROMs, BIOS images or firmware. The host glibc and dynamic loader remain OS-provided runtime components.
